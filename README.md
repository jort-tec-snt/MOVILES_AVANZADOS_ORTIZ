# MOVILES_AVANZADOS_ORTIZ

Programación en Móviles Avanzado — TECSUP.

`main` es la rama de **documentación y navegación**: cada `SEMANAxx/README.md` explica en qué rama está el código y cómo verlo.

## Los dos tipos de trabajo

| Tipo | Rama | Significado |
|---|---|---|
| Manual | `manual` | Desarrollado a mano, sin asistencia de IA |
| Con IA | `con-ia` | Desarrollado o mejorado con IA, con prompts documentados |
