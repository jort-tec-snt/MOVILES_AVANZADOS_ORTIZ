## Ver el trabajo

```bash
git switch manual
cd SEMANA05
open apple_lab05_IMC/apple_lab05_IMC.xcodeproj
```

Ejecutar en el simulador con **Run (⌘R)**. Las capturas y GIFs de demostración están en `SEMANA05/evidencias/` y se explican en el `README.md` de esa rama.

Volver a esta guía: `git switch main`.
